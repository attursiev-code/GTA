# Подбор ГТМ

Настольное приложение с графическим интерфейсом для подбора
геолого-технических мероприятий (ГТМ) на скважинах нефтяного
месторождения: ОПЗ, ГРП, РИР, ЗБС, смена насосного оборудования,
доперфорация пласта и вывод скважин из бездействия.

Программа анализирует параметры скважин по набору экспертных критериев,
формирует список кандидатов на проведение ГТМ, оценивает ожидаемый
прирост дебита нефти и экономический эффект (выручка, затраты, эффект,
срок окупаемости, ROI), после чего ранжирует рекомендации по эффекту.

## Требования

- Python 3.9+
- Tk (модуль `tkinter`), обычно входит в состав Python. На Linux при
  необходимости установите: `sudo apt install python3-tk`.

Внешние пакеты не требуются — используется только стандартная библиотека.

## Запуск

```bash
python3 main.py
```

## Быстрый старт

1. На вкладке **«Скважины»** нажмите **«Загрузить пример»**, чтобы
   заполнить таблицу демонстрационными данными (или импортируйте свой
   CSV-файл, см. `sample_data/wells_sample.csv` как образец формата).
2. Перейдите на вкладку **«Подбор ГТМ»** и нажмите **«Выполнить подбор»**.
3. Дважды щёлкните по строке результата, чтобы увидеть обоснование
   рекомендации.
4. При необходимости настройте пороговые критерии и экономические
   параметры (цену нефти, затраты на ГТМ и т.д.) на вкладке
   **«Параметры»**.
5. Сохраните проект (скважины + параметры) через **«Файл → Сохранить
   проект»** или экспортируйте результаты в CSV.

## Логика подбора ГТМ

Для каждой скважины проверяется набор критериев (пороги настраиваются
на вкладке «Параметры»):

| ГТМ | Условие срабатывания |
|---|---|
| ОПЗ | скин-фактор ≥ порога (загрязнение призабойной зоны) |
| ГРП | низкая проницаемость, умеренная обводнённость, запасы не выработаны |
| РИР | высокая обводнённость при сохранении остаточных запасов |
| ЗБС | критическая обводнённость и значимые остаточные запасы |
| Смена насоса | загрузка насоса выше/ниже допустимых пределов |
| Доперфорация | значительная доля невскрытой продуктивной толщины |
| Вывод из бездействия | скважина в простое, простой в допустимых пределах, есть запасы |

Скважины, на которых ГТМ проводилось недавно (менее заданного числа
месяцев назад), из подбора исключаются.

Для каждого сработавшего критерия оценивается ожидаемый прирост дебита
нефти, на основе которого с учётом темпа падения дополнительной добычи
рассчитывается накопленная добыча, выручка (по цене нефти за вычетом
удельных операционных затрат), затраты на мероприятие, экономический
эффект, срок окупаемости и ROI. Итоговый список сортируется по убыванию
экономического эффекта.
